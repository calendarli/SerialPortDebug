编程参数手册

自动回复 JavaScript 编程模式 · SerialFlow

基本结构函数参数 分组 global帧与位提取 返回参数完整示例

1. 基本结构

每次接收内容命中规则后，SerialFlow 调用一次 calculate。函数必须返回一个对象，对象键对应发送指令中的占位符。

function calculate(input, match, context) {
  return {
    参数名: 100
  }
}

发送指令使用：AA {{参数名}} BB

2. 函数参数

参数内容常用操作
input本次匹配到的 ASCII 或标准化 HEX 字符串input.slice(0, 2)
match正则完整匹配及捕获组；未使用正则时通常为空数组match[1]
context端口、命名捕获组、时间、参数等上下文context.port、context.groups.name

input[1]取得的是第 2 个字符，不是第 2 个 HEX 字节。

3. 分组全局变量

global 是所属自动回复分组的共享对象。同组规则可读写相同变量，不同分组互不影响。

global.counter ??= 0
global.speed ??= 100

global.counter++
global.speed = 200

??= 只在变量为 undefined 或 null 时赋初值，不会覆盖已有的 0、false 或空字符串。

变量会随本地配置和工程文件保存。分组的“重置”按钮会清空该组全部变量。

4. 提取 HEX 字节和位

const hex = input.replace(/\s+/g, '')
const byte0 = parseInt(hex.slice(0, 2), 16)
const byte1 = parseInt(hex.slice(2, 4), 16)

// byte1 最低位为第 0 位；这里提取第 3 位
const bit3 = (byte1 >> 3) & 1

使用正则捕获组

// 表达式示例：^AA ([0-9A-F]{2}) BB$
const value = parseInt(match[1], 16)

5. 返回值与编码

返回值必须是普通对象，且键名应与发送模板中的占位符一致。

return {
  计数: global.counter,
  速度: global.speed,
  状态: global.enabled
}
  • ASCII 发送：数字、布尔值会转换为文本。
  • HEX 发送：非负整数转换为偶数位 HEX，例如 10 → 0A。
  • HEX 字符串按原始 HEX 文本使用，请确保内容由完整字节组成。

6. 完整示例

接收一帧 HEX 数据，提取第 2 个字节及其第 3 位，同时累计分组计数。

/**
 * @param {string} input 匹配到的输入内容
 * @param {string[]} match 正则匹配结果
 * @param {object} context 串口上下文
 */
function calculate(input, match, context) {
  global.counter ??= 0
  global.counter++

  const hex = input.replace(/\s+/g, '')
  const byte1 = parseInt(hex.slice(2, 4), 16)

  return {
    计数: global.counter,
    字节1: byte1,
    位3: (byte1 >> 3) & 1,
    端口: context.port
  }
}

发送模板：AA {{计数}} {{字节1}} {{位3}} BB
